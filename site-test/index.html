Guide d''Utilisation

L''API-MARC fournit un accès programmatique aux contenus vidéo de plusieurs plateformes adultes.

Base URL

https://web-production-7115f.up.railway.app

Authentification

Aucune authentification requise pour le moment.

Formats de Réponse

Toutes les réponses sont en format JSON.

Codes de Statut

  • 200 - Succès
  • 400 - Requête invalide
  • 404 - Ressource non trouvée
  • 500 - Erreur serveur

Exemples d''Utilisation

JavaScript (Fetch)


// Recherche de vidéos
const response = await fetch(''https://web-production-7115f.up.railway.app/api/xnxx/search?q=amateur&limit=10'');
const data = await response.json();
console.log(data);

// Stream d''une vidéo
const streamResponse = await fetch(''https://web-production-7115f.up.railway.app/api/xnxx/stream/video123'');
const streamData = await streamResponse.json();

Python (Requests)


import requests

# Recherche de vidéos
response = requests.get(''https://web-production-7115f.up.railway.app/api/xnxx/search'', 
                       params={''q'': ''amateur'', ''limit'': 10})
data = response.json()
print(data)
